# LeadGen AI — FastAPI Backend

AI-powered lead generation API built with FastAPI + Python.

## Endpoints
- `GET /` — API info
- `GET /api/health` — Health check
- `POST /api/auth/register` — Register user
- `POST /api/auth/login` — Login
- `GET /docs` — Swagger UI (API docs)
